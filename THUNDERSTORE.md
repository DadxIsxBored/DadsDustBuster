# Thunderstore release checklist

1. Run `./build.ps1 -Package` from the project directory.
2. Upload `dist/DadsDustBuster-1.0.0.zip` to the `Dad_Is_Bored` Thunderstore team.
3. Use the package manifest description and the packaged README.
4. Confirm the dependency is `denikson-BepInExPack_Valheim-5.4.2350`.
5. Confirm the release version is `1.0.0`.
